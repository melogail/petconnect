# Frontend

Vue 3 single-file components rendered through Inertia v3. There is no client-side router; Laravel routes decide which page component renders.

## Layout of `resources/js`

```
app.ts               Inertia boot, Echo configuration, root layout
pages/               one component per Inertia::render() target
  Home.vue           feed with filters and "near me"
  Help.vue, Support.vue
  auth/              Fortify pages (login, register, 2FA challenge, …)
  pets/              Create, Edit (8-step wizard), Show
  profile/           Show, settings
  messaging/         inbox and conversation views
  settings/          profile, security, password
layouts/             RootLayout (toaster, document lang/dir), auth and settings layouts
components/
  ui/                shadcn-style primitives on reka-ui (Button, Card, Alert, Dialog, …)
  pets/              PetCard, filter panel, listing-type pills, share icons
  shell/             header, nav, unread badges
  notifications/     inbox items and message formatting
  support/           ticket form
composables/         shared behaviour (locale, geolocation, forms)
types/               TypeScript models mirroring the API resources
actions/, routes/, wayfinder/   generated by Wayfinder — git-ignored, never edited
```

## Routing from the client

Wayfinder generates typed functions for every controller action and named route:

```ts
import { show } from '@/actions/App/Http/Controllers/Web/PetController';
import { index as notifications } from '@/routes/notifications';

<Link :href="show.url(pet.slug)">…</Link>
```

Run `php artisan wayfinder:generate` after adding routes (the Vite plugin does this automatically in dev). Hard-coded URLs are a review failure.

## Inertia conventions

- Shared props from `HandleInertiaRequests`: `name`, `auth.user` (an `AuthenticatedUserResource`, never the raw model), `locale` (`current`, `direction`, `supported`), `translations` sent once per session, and flash messages rendered as toasts.
- Use `<Form>` / `useForm` for writes, `useHttp` for standalone requests (axios is gone in v3).
- Deferred props must render a skeleton while empty.
- Prefetching is on for links, so a GET must never write.
- Error events are `httpException` and `networkError`.

## Real time

`@laravel/echo-vue` composables subscribe to the private channel `App.Models.User.{id}` (authorised in `routes/channels.php`) for new-message and notification broadcasts. Locally the broadcaster is `log` unless `BROADCAST_CONNECTION=reverb`.

## Design system: "Aubergine & Lavender"

Defined in `.claude/PETCONNECT-STYLE-GUIDE.md` and implemented as CSS tokens in `resources/css/app.css`.

- **One accent.** Violet is the only chromatic colour; `--primary-600` in light mode, `--primary-400` in dark. Gradients are retired.
- **One solid button per surface.** Primary actions are solid violet; secondaries are a lavender wash.
- **Shadows over borders.** Cards lift with a diffuse shadow; borders are hairlines.
- **Type.** Manrope for UI, Newsreader for headings, Readex Pro for every Arabic role. Fonts are self-hosted through the Laravel Vite plugin's Bunny pipeline (`vite.config.ts`), not a Google Fonts link.
- Listing types have fixed semantic colours exposed through `LISTING_TYPE_PILL_CLASSES`; tests pin the mapping.

Dark mode re-tones rather than inverts. Both schemes meet WCAG AA on their stated surfaces.

## Brand

The chat-bubble pet-face mark is the only logo: `public/brand/sniffpal-*.svg|png`, `AppLogoIcon.vue`, favicon, email header and the default Open Graph image all use it.

## Build

```bash
npm run dev          # vp dev, HMR; or composer run dev for everything
npm run build        # vp build
npm run build:ssr    # + SSR bundle (Inertia SSR via @inertiajs/vite)
npm run check        # lint + format check
npm run types:check  # vue-tsc
```

A "Unable to locate file in Vite manifest" error means the build is stale: run `npm run build` or start the dev server.
