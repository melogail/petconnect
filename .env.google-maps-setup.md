# Google Maps API Configuration

## Required Environment Variable

To use Google Maps, you need to add your API key to the `.env` file:

```env
VITE_GOOGLE_MAPS_API_KEY=your_api_key_here
```

## Getting a Google Maps API Key

1. Go to the [Google Cloud Console](https://console.cloud.google.com/)
2. Create a new project or select an existing one
3. Enable the following APIs:
    - Maps JavaScript API
    - Geocoding API (for reverse geocoding)
4. Go to "Credentials" and create an API key
5. Copy the API key and add it to your `.env` file

## Important Notes

- The API key should start with `VITE_` to be accessible in the frontend
- After adding the API key, restart your development server (`npm run dev`)
- For production, make sure to restrict your API key to your domain

## Current Status

The Google Maps integration is complete. Once you add the API key, the map will:

- Display your current location automatically on page load
- Allow clicking on the map to select a location
- Update the marker position when clicking
- Show coordinates at the bottom of the map
- Reverse geocode to fill in address fields
